## 1. O01 — LabelLedger — reference-label change intelligence and generic label drift detection

**Final score 6.95** (weighted 7.35, penalties −0.40) · sector `pharma-regulatory` · Solo-founder friendly, AI-native, Low-capital, Fast-to-market, Enterprise-focused, Long-term infrastructure

- **Concept:** Version-control every public drug label, explain each change section by section, and flag generic labels that have drifted out of sync with their reference.
- **Customer:** Labeling and regulatory-affairs teams at generic manufacturers (US ANDA holders first, many run from India/Bangladesh), plus the regulatory consultancies that serve them.
- **Painful problem:** Generic labels must track reference-label changes; teams compare 30-80 page labels by hand, miss updates, and must produce side-by-side comparisons for every labeling submission.
- **Existing alternatives:** Manual DailyMed/Drugs@FDA checks, FDA SrLC database, enterprise label-intelligence platforms, consultancies.
- **Why alternatives fall short:** SrLC excludes ANDAs, non-safety sections and pre-2016 history; enterprise tools are quote-only and priced for large companies; nothing self-serve is generics-first.
- **Proposed solution:** Watchlists of reference labels, deterministic section-aware redlines, severity triage, drift reports against your own labels, AI-written impact summaries grounded in the diff, submission-ready comparison drafts.
- **Required technology:** SPL XML parsing (LOINC sections), alignment and token diffing, fuzzy sentence matching, rules-based severity, grounded LLM summaries, scheduled polling, web app.
- **MVP scope:** Parse/diff/triage engine + drift checker + HTML/Markdown/JSON reports + watchlist poller + minimal web UI (built in this session).
- **Development complexity:** medium
- **Initial capital:** <$1k to first revenue (hosting, domain, LLM tokens)
- **Pricing model:** Free public label history + weekly digest; Pro $199/mo (50 watched labels); Team $599/mo (300 labels, drift reports, comparison drafts); Enterprise/API custom.
- **Customer acquisition:** Free weekly 'reference label changes' digest; personalised drift snapshots built from public data as outbound hooks; LinkedIn RA community; programmatic label-history pages.
- **Competitive landscape:** Dr.Evidence (728k labels, RLD alerts), Basil Systems, Freyr/Freya, IQVIA RIM Smart Labeling, Sarjen KnowledgeNet, in-house scripts.
- **Technical defensibility:** Accumulated version archive (captured from day one), generics-specific workflow, trust in accuracy, multi-authority coverage over time, distribution via public layer.
- **Regulatory / security concerns:** Decision support on public data; no PHI. Accuracy liability managed by deterministic diffs, provenance and human review; never auto-submits.
- **Main failure risk:** Target buyers already satisfied by incumbents or by manual process; willingness to pay for 'monitoring' alone proves low.
- **Evidence required before investing:** 10 interviews confirming manual effort and missed updates; 3 paid pilots >= $200/mo within 60 days; drift snapshots that prospects call accurate.
- **Evidence:** E01 (primary), E02 (secondary), E03 (primary), E04 (vendor), E05 (vendor), E06 (vendor), E22 (primary), E23 (observation), E25 (secondary)
- **Why this score:** Regulator-defined obligation, fully public structured data, demonstrable value before any customer shares data, and a data-infrastructure path. Competition is real, so positioning and validation speed matter.
